## Real macOS runtime

- The re-downloaded final release DMG scanned 897 launchd jobs with 15 parser/visibility warnings and 169 deterministic findings as the current unelevated user.
- Final package local profile: 448.8 ms warm launch against the 1,500 ms product target; launchd collection took 53.0 ms, including 7.8 ms for bounded domain queries, and diagnostics took 8.5 ms.
- The hosted release profile measured 2,016.4 ms warm launch against its 5,000 ms smoke ceiling. Collection took 109.3 ms against 1,000 ms and diagnostics took 13.8 ms against 500 ms. The separate hosted profile prevents variable WebKit startup from hiding scan regressions or silently replacing the local product target.
- Collection and diagnostics emit content-free structured receipts with counts and timing only.
- Light, dark, export-review, and 731×528 minimum-window captures were inspected from a packaged pre-final-hardening app and retained as visual smoke evidence.
- The macOS accessibility tree exposed named navigation, search, filters, tabs, job buttons, inspector headings, theme control, export dialog, checkboxes, and status text.
- Direct spoken VoiceOver behaviour remains a manual user gate; automated semantic/AX and keyboard-oriented coverage passed.
