# JobGlass

> See what runs next.

JobGlass is a local-first, read-only desktop view of native scheduled jobs across macOS, Linux and Windows. It is currently under v0.1.0 development from an approved specification.

Read the [specification](SPEC.md), [support matrix](SUPPORT_MATRIX.md), [security boundary](SECURITY.md) and [implementation plan](tasks/plan.md).

## Status

The first commit intentionally contains product contracts only. Implementation happens on `feat/production-v1` in the required production worktree.
